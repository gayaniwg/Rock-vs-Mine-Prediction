# Project Overview: Sonar Object Classification

This project focuses on classifying objects as either metal (mines) or rocks using the Sonar Mines vs. Rocks dataset. The dataset consists of 60 numerical features per record, each representing the energy captured within specific frequency bands, ranging from 0.0 to 1.0. These features are derived from sonar return data, integrated over time. The goal is to accurately predict whether an object is a rock or a mine based on these features. The dataset is labeled with 'R' for rocks and 'M' for mines (metal cylinders), with the labels ordered by increasing aspect angle, though the angle itself is not directly encoded in the data.
